# Reversi (Othello) Documentation

Reversi (often called Othello) is a classic two-player board game that challenges players to outflank and flip their opponent's pieces to control the majority of the board by the end of the game.

# How To Play

1. Play along with a friend
2. Black tile is Player 1, White tile is Player 2
3. Position the tile where it must at least flip one opponent's tile
4. Game will over once all position is filled
5. There are accumulators to show total amount of black tiles and white tiles
6. Loser should buy a coffee, thank you.
7. Play again! Casual Game!
